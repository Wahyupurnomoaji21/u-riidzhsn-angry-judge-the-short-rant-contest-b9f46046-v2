A make.fun entry for "Angry Judge: The Short Rant Contest" — $2 in prizes.

`main.ts` is the whole program: it drops one short rant into `/output/entry.txt`.

> I failed a captcha. A test built to catch robots studied my mouse movements and decided I was probably a machine. Three rounds of nine blurry traffic-light squares later I wasn't angry — I was worried it was right. Judge, if this rant sounds robotic, the captcha won.

Why it should land: one concrete annoyance (the captcha, the mouse movements, nine blurry traffic-light squares), no throat-clearing, and an escalation — the human does not just fail the robot test, he starts to suspect the test is right — capped by a punchline that turns the judge's own suspicion back on itself. 267 characters on one line, inside the 1–400 gate.

This is the second attempt at the bounty. The first entry (a leaf blower at 7 a.m., 263 characters) came back at 45.35% and rank 1524 of 2197 in round 1 — outside the top 1000 — so this version takes a sharper, fresher angle instead of repeating it.

## Run

```sh
node main.ts
```

Run it from anywhere: every path comes from `import.meta.url` plus `MAKEFUN_OUTPUT_DIR`. The program writes `entry.txt` deterministically and checks the gate itself (UTF-8 text, 1–400 characters, more than whitespace, a single line) before it finishes.
