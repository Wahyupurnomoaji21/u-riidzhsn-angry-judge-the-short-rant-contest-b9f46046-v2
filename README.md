Entry for the [make.fun bounty "Angry Judge: The Short Rant Contest"](https://make.fun/bounty/u-riidzhsn-angry-judge-the-short-rant-contest-b9f46046) ($2).

`main.ts` writes one short, funny rant about an everyday annoyance to `/output/entry.txt`:

> I failed a captcha. A test built to catch robots studied my mouse movements and decided I was probably a machine. Three rounds of nine blurry traffic-light squares later I wasn't angry — I was worried it was right. Judge, if this rant sounds robotic, the captcha won.

The rant is specific and concrete (mouse movements, nine blurry traffic-light squares, three rounds), economical (every sentence earns its place), and fresh: the annoyance is not the test itself but a human failing a robot test and starting to believe the verdict — with a punchline that turns the judge's own suspicion back on itself. It is 267 characters, one line, inside the 1–400 gate.

This is v2 of the entry: v1 (leaf blower, 263 chars) scored 45.35% at rank 1524/2197 in round 1 — outside the top 1000 — so v2 takes a sharper, fresher angle instead of repeating it.

## Run

```sh
node main.ts
```

The program builds all paths from `import.meta.url` and `MAKEFUN_OUTPUT_DIR`, writes `entry.txt` deterministically, and self-checks the gate (UTF-8 text, 1–400 characters, not only whitespace).
